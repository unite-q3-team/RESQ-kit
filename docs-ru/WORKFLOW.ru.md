# Workflow — декомпиляция нового мода

> Перевод [../WORKFLOW.md](../docs/WORKFLOW.md); при расхождениях приоритет у английского оригинала.

Этот набор — только **QVM-рекомпилятор**: любой Quake 3 VM → C89 → q3lcc → играбельный QVM. Приёмка: `seqdiff` 0 против оригинального модуля (некоторые UI-образцы держат известный mismatch `trap_S_StartLocalSound` в Driver Info; большинство модов должны совпадать).

**Порт на стоковые исходники** (переписывание тел на baseq3a) — другой продукт. Не начинайте его, пока пользователь не попросит.

Постоянные приказы: [AGENT.ru.md](../AGENT.ru.md).

## Новый мод → identity C (затем опциональный rebuild)

```
probe_emit <mod.qvm> out.c syscalls.asm --no-typed
q3lcc -DQ3_VM -S out.c
q3asm -vq3 -m -o name syscalls.asm name.asm
```

Обёртки набора:

```powershell
.\scripts\emit_qvm.ps1 -Qvm work\qagame.qvm -OutDir work\qagame
.\scripts\build_qvm.ps1 -SrcDir work\qagame -Stem qagame
```

- Начинайте с untyped emit (дефолт; `--no-typed` — no-op). Это универсальный эмиттер: blob, `loc_0`, gotos, широкие прототипы `va` / `G_Printf`.
- Опционально `[foo.names] [foo.sigs]` (детектируются по суффиксу) для человеческих имён функций и фреймов. Это не data-оверлей.
- Typed emit использует опциональный оверлей `types.rs`. Он поставляется пустым; заполняйте его под конкретный модуль перед `--typed`.

pk3 / git commit: только по запросу пользователя.

## Имена vs оверлей

| файл | роль |
|------|------|
| `.sigs` | автоматически из байткода (фрейм / арность / ret) |
| `.names` | align + ручные переопределения |
| `.asm` | вывод q3lcc |
| `types.rs` | опциональный ключ data-space конкретного мода (базы, strides, паддинги структур); поставляется пустым — не используется с `--no-typed` |

## Бисекция

Если типизированная пересборка ведёт себя плохо: `probe_emit --no-typed` и сравните. Если `--no-typed` в порядке — виноваты оверлей/косметика, а не CFG/blob. Никогда не запускайте typed emit с незаполненным или чужим ключом.
