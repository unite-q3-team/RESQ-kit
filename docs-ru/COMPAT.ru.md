# Совместимость на этапе emit

> Перевод [../COMPAT.md](../docs/COMPAT.md); при расхождениях приоритет у английского оригинала.

Честная декомпиляция сохраняет баги, бывшие во входном `.qvm`. Часть из них стреляет только на современном железе. `probe_emit` может переписать сгенерированный C после emit, чтобы следующий rebuild нёс фикс.

Оба места ниже найдены на конкретных образцах модулей. В другом моде их может не быть. Не считайте, что они применимы; не копируйте номера insn на другой QVM.

## Driver Info (сэмпл UI)

Симптом: `Setup → System → Graphics → Driver Info` → `program tried to read out of data segment`.

Причина: UI-хелпер делает `strcpy(scratch@365972, extensions@190436)`. Scratch — 1024 байта (`365972..366996`). Длинный `GL_EXTENSIONS` затирает таблицу указателей на строки.

Правка в emit:

```text
fn_66367(365972, 190436)   →   fn_76610(365972, 190436, 1024)
(strcpy)                        (Q_strncpyz)
```

Обрезку `extensions_string` в `UI_GETGLCONFIG` пробовали и отбросили: upstream Quake3e так не делает.

## ClientSpawn / `FL_NO_BOTS` (сэмпл qagame)

Симптом: `spmap q3dm0`, игрок сходит со стартовой платформы, заходит бот Crash → зависание в `ClientSpawn`.

Причина: lcc оставил указатель на spawn-spot живым через обратное ребро `continue` в `FL_NO_BOTS`. Голова цикла видит ненулевой spot, пропускает `SelectSpawnPoint` и вечно повторяет тот же nobots-пад. Оригинальный байткод имеет ту же форму; orig обычно выпутывается, потому что его первый выбор после `GAME_INIT` — бот-ок. Rand-поток rebuilt чаще первым берёт nobots-пад. Не ограничивайте retry-цикл — orig и без него выживает.

Правка в emit на метке retry:

```text
L123403:
  *(int*)&loc_0[2000] = (int)vmMain;

→

L123403:
  *(int*)&loc_0[104] = (int)vmMain;   /* clear spot */
  *(int*)&loc_0[2000] = (int)vmMain;
```

## Правила

Баги входного VM чините в эмиттере. Не держите постоянных ручных правок в сгенерированном `.c`. Новые compat-сайты логируйте здесь.
